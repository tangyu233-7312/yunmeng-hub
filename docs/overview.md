# 云梦枢 · 系统总结（功能 / 技术 / 架构）

> **云梦枢（YunMeng Hub）**——一个"异构大模型交互式叙事引擎"。
> 名字取意：**云**（云端 AI）+ **梦**（沉浸式叙事）+ **枢**（系统中枢，谐音"书"，指世界书与故事线）。
>
> 本科毕业设计项目。本地部署、单机可跑：FastAPI + **SQLite（默认）/ MySQL（可选）** + ChromaDB 后端，
> 一个**零构建**的浏览器控制台（原生 ES Module，不装 npm、不用框架）。
>
> 本文是"给人看的总览"：它做了什么、有哪些功能、用了什么技术、怎么验证。
> 逐轮的开发细节见本机的 `docs/dev-notes/handoff.md`（不在仓库里），论文素材见 `docs/paper-materials.md`。

---

## 1. 它解决什么问题

市面上的 AI 角色扮演产品大多是"一个模型 + 一段设定"的黑盒。这个项目想做的是**叙事引擎**：

| 问题 | 本项目的做法 |
|---|---|
| 模型来自不同厂商、参数与错误码各不相同 | 统一调用层：**两个协议**（OpenAI 兼容 / Anthropic）+ 错误码归一化 + 参数被忽略时如实回报 |
| 长篇叙事会"忘设定、忘剧情" | 两条记忆通道：**世界书**（关键词触发）+ **向量长期记忆**（语义召回），再用 RRF 融合 |
| 角色设定散落在聊天里、不可复用 | **角色卡**（SillyTavern 互操作，PNG/JSON 导入导出）+ **世界书**独立成表 |
| 提示词是个黑盒，用户不知道发了什么 | **装配可预览**：界面能看"这一轮到底发了什么"，且与真实请求**同源**（同一个函数） |
| 模型输出的状态（HP/好感/任务）无法被程序使用 | **状态协议**：模型在回复末尾输出 `<state>`，引擎解析、落库、做**漂移曲线**校验 |
| 想加功能就得改核心代码 | **声明式插件**：四种能力（正则替换 / 提示词注入 / CSS 主题 / 骰点），不执行第三方代码 |
| AI 说"我掷出了 18"其实是在编 | **骰子由后端受控求值**，模型只负责叙述 |

## 2. 功能总览

| 模块 | 它能做什么 |
|---|---|
| **角色卡** | 导入/导出 SillyTavern（PNG 直接拖入、JSON）、Character Card V2 互操作、公开卡库、重名允许、删除保护（先问清关联会话） |
| **HTML 开场白** | 卡片里的"状态栏卡片"会被**真正渲染**（iframe 沙箱、禁脚本、CSS 清洗、宏替换、图片兜底） |
| **VN 模式** | 立绘/表情跟着状态栏字段变，声明式配置 |
| **世界书** | 独立表；条目按**关键词触发**或常驻；与角色卡关联；删除保护 |
| **叙事会话** | SSE 流式逐字输出、消息级**编辑 / 撤回 / 重新生成**、上下文预算与裁剪、提示词透明预览 |
| **状态系统** | 字段由**角色卡/世界书**定义（`state_schema`）、原文留档、遥测、漂移曲线、"状态探针"提示 |
| **长期记忆** | 向量召回 + 关键词触发 + **RRF 混合检索**；记忆管理面板（看/搜/增/删/清）；记忆锚点 |
| **剧情总结** | **分层合并**压缩；**用户可控**（提醒但不自动花钱） |
| **提示词预设** | 酒馆式 completion preset 导入导出、块级启停、内置守卫规则（身份认知 / 剧情不跑偏 / 输出长度） |
| **模型配置** | 多套配置并存、两协议、试连、**备用模型自动接管**、思考强度三表达 + **生效性探测**、上下文预算 |
| **翻译中间件** | 跨语言对话：单一"目标语言" + 源语言自动识别；三档（关 / 只提示词 / 真翻译）；**逐条翻译**按钮；翻译请求降思考；按 token 记账 |
| **骰子插件** | 触发词掷骰，随机数由**服务端**求值，协议记号从模型输出里剥离 |
| **插件系统** | 四种声明式插件；只允许从 GitHub 安装；**不执行任何第三方 JS**；CSS 白名单清洗；内置目录 + **有更新一键升级** |
| **纯聊天** | 不选角色卡的"API 体检台"，用来确认自己的模型配置通不通 |
| **可观测** | 请求日志抽屉（逐次调用留痕）、逐轮真实用量落库、`token_accuracy.py` 估算精度对照 |
| **界面/主题** | 深色沉浸主题「云梦枢 · 星云暗涌」（星云 + 星点 + 毛玻璃 + 量子紫/极光青），一键开关、完全可逆 |

## 3. 关键功能详解

### 3.1 统一大模型调用层（项目的技术核心）
- **两个协议**：`openai_compatible`（含各类兼容网关）、`anthropic`；流式与非流式统一成一个 `ChatResult` / `StreamChunk`。
- **错误码归一化**：把厂商五花八门的报错收敛成 7 类，前端给出**可操作**的排查顺序。
- **参数"被接受但被忽略"**：`reasoning_effort` 这类参数有的厂商照收不报错却毫无效果 —— 项目提供**探测接口**（真实调用两次对比思考量）并把结论绑定到适配器实例，只在探测确认支持时才下发。
- **备用模型**：主模型失败时按配置自动接管，且**接管这件事会在回复里如实说明**。
- **适配层替用户做的任何决定都必须回报**（`notes` 机制）：裁剪了几条、忽略了哪个参数、谁接管的。

### 3.2 状态协议与"状态探针"
模型每轮在回复末尾输出 `<state>{...}</state>`，字段由角色卡的 `state_schema` 或世界书定义。
引擎解析后：落库（含**模型输出的原文**，供"看作者原格式"）、渲染成消息下方的一行状态条、
写入遥测（`state_meta_json`），并支持导出**漂移曲线**（校验"有状态"到底值不值）。
没有状态栏的会话会明确显示"这张卡没有定义状态栏格式"，而不是装作没有这一回事。

### 3.3 记忆：两条通道 + 融合
- **世界书**：原先是全量注入，现在按关键词触发（省 token 且更准）。
- **向量长期记忆**：写入"给人看的那一份"文本，按语义召回。
- **混合检索**：两路结果用 **RRF** 融合，并记录检索指标（命中了几条、被预算丢掉几条）。
- **剧情总结**：分层合并、本地压缩（**不额外花一次模型调用**）；到点只提醒，总结与否由用户决定。
- 记忆坏了只降级、绝不拖垮主流程（所有记忆函数不抛异常）。

### 3.4 插件系统（声明式，不执行第三方代码）
四种能力：`regex`（正则替换，只改发给模型的内容）、`prompt`（提示词注入，可选位置与深度）、
`css`（控制台换肤）、`dice`（跑团骰点）。
安全边界写死在实现里：安装只允许 GitHub（重定向后再查一次域名）、有体积与条数上限、
CSS 过白名单清洗（挡 `@import` / `expression()` / `javascript:` / `</style>` 逃逸）、**从不 eval**。
内置目录里的条目是"拷贝式安装"，因此额外提供 **`有更新` → 一键更新** 的升级通道。

### 3.5 界面与视觉
- **零构建**：原生 ES Module + 动态生成的 importmap（URL 带构建指纹），改前端不需要打包步骤；
  `boot.js` 负责"浏览器缓存了旧版本"时的自愈（避免出现"新 JS + 旧 JS"混用导致整页白屏）。
- **主题即插件**：组件颜色全部走语义变量（`--surface*` / `--*-border` / `--brand` …），
  所以一条 CSS 插件就能整体换肤；内置「云梦枢 · 星云暗涌」把深空底、星云、星点、
  毛玻璃、量子紫（状态色）/极光青（交互色）都做成了变量与少量规则。
- **卡片 HTML 用 iframe 渲染**：沙箱隔离（`allow-same-origin`、**不给** `allow-scripts`），
  卡片自带 `<style>` 污染不到控制台；iframe 文档头在渲染时注入当前主题变量（否则深色下会是一块白）。

| 层 | 选型 | 说明 |

| 向量库 | **ChromaDB 1.5.9**（PersistentClient） | 余弦距离；嵌入用 **ONNX 本地模型 all-MiniLM-L6-v2（384 维）**，也可切到 API 嵌入后端 |

| 日志 | **loguru 0.7.3** | 分文件、可读 |
| 前端 | **原生 ES Module + CSS 变量**（无框架、无 npm、无构建） | 11 个 JS 文件（4 核心 + 7 视图）+ 1 张样式表 |
| 测试 | **pytest 9.1.1**（28 个测试文件） | 全部同步（`TestClient`），无 `pytest-asyncio` |

## 5. 一次对话的完整数据流

```
浏览器控制台
  │  ① POST /api/v1/narrative/sessions/{id}/stream   (SSE)
  ▼
API 层（鉴权 → 校验 → 组装）
  │  ② 用户消息先落库（模型失败也不会吞掉用户打的字）
  ▼
叙事引擎 engine.build_session_prompt()
  │  ③ 装配：系统提示词（内置守卫/角色卡/世界书/预设/插件注入）
  │  ④ 上下文预算与裁剪（本地估算，决定丢哪些历史）
  │  ⑤ 记忆：世界书关键词触发 + 向量召回 → RRF 融合 → 装填
  ▼
统一 LLM 调用层（适配器 + 备用模型 + 参数回报 notes）
  │  ⑥ 流式返回：meta / notes / reason / delta / translating / done
  ▼
浏览器逐字渲染（SSE → 气泡）
  │  ⑦ 回复落库：正文、思考、状态原文、逐轮真实用量
  ▼
状态解析 → 状态条 + 遥测；翻译中间件（若开）→ 追加译文
```

## 6. 工程与质量保障

**测试不只有单测**——CSS/JS 的 bug 单测看不见，所以项目自建了浏览器探针：

| 资产 | 规模 | 作用 |
|---|---|---|
| `pytest` | **870 项通过**（28 个文件） | 接口契约、数据一致性、提示词装配、安全边界、状态/记忆/翻译/插件 |
| `scripts/smoke_test.py` | **184 项通过** | 对**运行中的服务**做真实 HTTP 冒烟，并直连数据库核对"接口说的与库里发生的"一致 |
| `scripts/ui_probe.py` | **147 项通过** | 无头 Edge + **CDP** 真实点击：起假模型、造数据、点界面、读计算样式、留档截图 |
| `scripts/benchmark.py` | 退出码 0 | 检索/状态的混合与可复现 benchmark（固定种子） |
| `scripts/token_accuracy.py` | 退出码 0 | 本地 token 估算 vs 厂商真实 `prompt_tokens`（首批样本 n=3：比值 **1.185**、思考占输出 **53.6%**） |
| `scripts/fake_openai_server.py` | — | 本地假 OpenAI 服务：**不花钱、不联网**跑通流式全链路 |

**三条反复自我约束的原则**（每条都对应真实事故，详见 `docs/pitfalls.md`）：
1. **拒绝静默降级**：宁可报错，也不偷偷帮用户关掉他设的参数。
2. **预览必须与真实请求同源**：装配函数只有一个，界面与线上走同一条路。
3. **能被用户看见的状态必须如实回报**：裁剪了几条、忽略哪个参数、谁接管了、跳过翻译的原因。

**视觉断言的"四种画法"**：背景色 / 渐变 / 半透明 / 点状高光，每一类都要有对应断言 ——
这个探针的采样器为此修了四次（透明漏检 → 渐变漏检 → 半透明误判 → 星点被当成白块）。
同一课也适用于边框与 iframe 子文档。**"没测到"和"通过"长得一模一样**，所以每次都会把
"跳过了哪些元素、为什么跳过"一起打印出来。

## 7. 明确**没有**做的（如实列出）

| 没做 | 原因 |
|---|---|
| Electron 打包 | 用户明确"先别急"；图标素材已按打包需要准备好（`assets/icon/logo-1024.png`） |
| "PNG 导入即自动当立绘" | 见本机的 `docs/dev-notes/handoff.md` §29.2：PNG 里没有可靠的立绘语义，宁可不做也不假装 |
| TTS / 生图 / 图片描述 / 快捷回复 | SillyTavern 的这些扩展**必须执行第三方 JS 或接外部服务**，与本项目"插件不执行代码"的红线冲突；界面上如实列出并说明 |
| 群组聊天 | 已从计划中删除（定位是"与人设对话"，不是多人群聊） |
| 云端部署 / 多租户 | 定位是本地单机毕设系统；但已做**用户隔离**（数据按 user_id 隔离） |

## 8. 快速上手

```bash
# 1) 依赖
python -m pip install -r requirements.txt
# 2) 配置：复制 .env.example 为 .env（**默认 SQLite，什么都不用填**；
#    想用 MySQL 就设 HNE_DB_BACKEND=mysql 并填 HNE_MYSQL_* ）
# 3) 建表
python scripts/init_db.py
# 4) 起服务（代码改动用重启；只改前端刷新页面即可）
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 5) 打开控制台
#    http://127.0.0.1:8000/console/     （接口文档 /docs）
```

**不想花 API 费用也能体验**：先跑 `python scripts/fake_openai_server.py`，
在「模型配置」里把地址指向它，就能看到完整的流式叙事效果。
