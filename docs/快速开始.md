# 快速开始

> 返回 [README](../README.md)

## 安装与启动

使用 Python 3.13。在仓库根目录执行：

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

打开 [控制台](http://127.0.0.1:8000/console)，注册账号，然后在「模型配置」中填写服务商地址、API Key 和模型名。接口文档位于 `/docs` 和 `/redoc`，健康检查位于 `/health`。

无需先建 `.env` 或手动建表。默认使用 SQLite；首次启动自动建表，并将缺失的密钥写入 `config/.secrets.env`。本地 ONNX 嵌入模型首次使用会下载约 80 MB，之后使用本机缓存。

安装开发工具与测试依赖：

```powershell
./.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
```

运行依赖与开发工具分别列在 `requirements.txt`、`requirements-dev.txt`。这两份文件固定直接依赖版本，传递依赖由 pip 解析，并非完整的环境锁文件。

## 配置与数据位置

需要自定义设置时复制模板：

```powershell
Copy-Item .env.example .env
```

所有配置保留 `HNE_` 前缀，避免与系统通用变量冲突，并兼容已有版本。设置值通常按「环境变量 → `.env` → 默认值」取值；数据根目录 `HNE_DATA_DIR` 是进程环境变量。

| 内容 | 源码默认位置 | 安装版 / Web 发行版默认位置 |
|---|---|---|
| SQLite | `data/app.sqlite3` | `%APPDATA%/云梦枢/data/app.sqlite3` |
| 向量库 | `data/chroma/` | `%APPDATA%/云梦枢/data/chroma/` |
| 自动密钥 | `config/.secrets.env` | `%APPDATA%/云梦枢/config/.secrets.env` |
| 手工配置 | `.env` | `%APPDATA%/云梦枢/config/.env` |

已有密钥会保留。备份时应覆盖数据库、向量库、媒体文件以及配置和密钥。改掉 Fernet 密钥会使已保存的 API Key 无法解密。

## 可选 MySQL

默认 SQLite 适合本机使用；MySQL 需要自行安装服务并创建数据库与账号。两种后端共用业务代码，但应分别验证。

```ini
HNE_DB_BACKEND=mysql
HNE_MYSQL_HOST=127.0.0.1
HNE_MYSQL_PORT=3306
HNE_MYSQL_USER=narrative_app
HNE_MYSQL_PASSWORD=你的密码
HNE_MYSQL_DB=narrative_engine
```

明确设置 `HNE_DB_BACKEND`。旧配置仅有 MySQL 字段时，程序会继续推断使用 MySQL，避免旧数据看起来丢失。启动时自动补齐表结构；迁移脚本与数据库说明见 [项目结构](项目结构.md)。

## 开发与验证

```powershell
./.venv/Scripts/python.exe -m pytest -q --junitxml=.pytest-data/results.xml
./.venv/Scripts/python.exe scripts/verify_zero_config.py
./.venv/Scripts/python.exe -m ruff check app scripts tests desktop/backend_entry.py desktop/scripts
./.venv/Scripts/python.exe scripts/check_docs.py
cd desktop
npm test
```

完整说明见 [测试与验证](测试与验证.md)，包括真实 API 的 `--live` 开关、MySQL 专用测试库、模型缓存、跳过原因和当前实测结果。测试数量以每次运行报告为准。

桌面端开发与打包见 [desktop/README.md](../desktop/README.md)。重新命名或移动源码目录后，Python 虚拟环境中的命令启动器可能仍引用旧路径，应重新创建虚拟环境；平时推荐使用上面所示的 `python.exe -m ...` 命令。
