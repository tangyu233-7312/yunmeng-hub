# 版本日志与开发进度

## 版本与更新日志

当前版本 **v0.4.0**（后端 `APP_VERSION`、桌面壳 `desktop/package.json` 同一套版本号，
安装包文件名随之为 `云梦枢 Setup 0.4.0.exe`）。下面是给人看的变更摘要；
每条 Release 都以本段为准。

### v0.4.0 — 卡片能"带自己的状态"了

**新能力**

- **消息分段渲染**：一条回复里有正文也有 HTML 卡片时，按原文顺序**交替显示**
  （以前是整条消息二选一：要么全渲染进 iframe，要么全当纯文本）。
  卡片围栏认 ` ```html ` 与 ` ```+<body> ` 两种写法，卡片各带「渲染视图 / 源码」页签。
- **卡自带状态块**：角色卡作者写在自己开场白/回合里的状态，从**五种来源**识别 ——
  `<state>` 标签、` ```json ` 围栏、酒馆式 `<UpdateVariable>` 指令块、
  `<script type="application/json">`、卡片自带的 HTML 状态块。
  识别到就**原样保管**到新表 `card_states`（按「会话 + 形状」分桶），
  **不注入提示词**、不改写正文。
- **两套状态互相让位**：作者卡的状态占据主位时，系统状态栏自动**收起成一条细条**；
  系统状态优先时，作者卡状态反过来让位。面板里带「收起」按钮，随时能切回去 ——
  不会出现两条状态栏都把对方挤没了的死锁。
- **偏移检测保持保守**：只判定**字段消失**与**类型变化**，不猜"值改了是不是错"。

**升级说明**

- 新增的 `card_states` 表由后端启动时自动创建，两端数据库都适用；
  **没有**改动任何既有表结构，所以升级不需要手动迁移，
  旧数据（会话、角色卡、记忆）原样照读。
- 卡状态块是**新表新路径**，不改变任何既有行为：忽略它也不会影响原有的系统状态栏；
  真认错了（把正文当状态藏起来），关掉内置状态栏就能看到原始正文。
  识别规则只在后端实现一份、前端只读结果，前后端不会各说各话。

### v0.3.0 — 首个可安装版本

- Electron 桌面壳 + PyInstaller 打包后端 + Windows NSIS 安装包（三阶段打通）。
- **装完即用**：默认 SQLite 单文件存储，无需安装数据库服务，表与密钥首次运行自建。
- 交互式叙事引擎主体：多协议 LLM 适配、提示词预设、世界书、向量记忆与混合检索、
  剧情总结分层合并、骰子插件、VN 模式、翻译中间件、对话分支、记忆面板与漂移曲线。
