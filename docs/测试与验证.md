## “1121 passed” 和“每个 passed 都有用吗”

README 里的 **1121 passed / 3 skipped** 没有同一提交的 JUnit 报告，不能追认为事实。`863 passed / 4 skipped` 是 2026-11-20 的重构基线；2026-11-21 的全量结果见上表。通过数都不代表覆盖率或变异分数：单元测试验证单条规则，集成测试验证组件组合，验收测试验证启动边界，参数化测试则会为不同输入分别计数。

本轮保留了针对性的故障注入检查：健康状态、锚点超限、密码校验、SQL 通配符和 Web boot 刷新各注入一个错误，测试应失败。这只说明这些样本有检测能力，不能证明所有测试都有效。
