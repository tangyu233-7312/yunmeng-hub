## “1121 passed” 和“每个 passed 都有用吗”

README 里的 **1121 passed / 3 skipped** 没有同一提交的 JUnit 报告，不能追认为事实。本次重新执行得到 863/4，是重构后的收集结果；它也不代表 863 条都同等重要。单元测试只验证一个明确业务规则，集成测试验证组件组合，验收测试验证启动和环境边界。参数化的一行仍会收集多个输入场景，所以函数数量和 passed 数都不能代替覆盖率或变异分数。

本轮保留了针对性的故障注入检查：健康状态、锚点超限、密码校验、SQL 通配符和 Web boot 刷新各注入一个错误，测试应失败。这只说明这些样本有检测能力，不能证明所有测试都有效。
