云梦枢 · Web 版（绿色免安装）
======================================================================

这是什么
--------
云梦枢（YunMeng Hub）的**浏览器版**：不用安装，解压后双击一个文件就能用，
界面在你自己常用的浏览器里打开。

它和安装版（YunMengHub-Setup-x.y.z.exe）用的是**同一个后端程序、同一份前端**，
功能完全一致，区别只有两点：

  · 安装版：装进系统，生成开始菜单图标，用程序自带的窗口打开；
  · 本压缩包：解压到任意目录，双击启动，用你的浏览器打开。
             不写注册表、不建开始菜单、不需要管理员权限。


怎么用（三步）
--------------
1. 把这个压缩包**整个解压**到一个你找得到的地方
   （不要在压缩软件的预览窗口里直接双击运行 —— 那样 backend.exe 用不了）。

2. 双击「启动云梦枢.cmd」。

3. 稍等几秒，浏览器会自动打开控制台（http://127.0.0.1:端口/console）。
   第一次打开会让你注册一个本地账号 —— 这个账号只存在你自己的电脑上。


用完之后
--------
关掉那个黑色的命令行窗口（或按 Ctrl+C）就停止了。
窗口在，服务就在；窗口关了，服务就停。不需要"卸载"。


数据存在哪里
------------
默认：%APPDATA%\云梦枢\
  · data\app.sqlite3        你的账号、角色卡、对话、世界书（一个 SQLite 文件）
  · config\.secrets.env     自动生成的密钥（不要删除，删了就解不开已存的 API Key）
  · data\chroma\            长期记忆用的向量库

★ 数据**不在**解压目录里，所以：
  · 换个地方解压、或者把整个目录删掉重下，数据都还在；
  · 想换个位置存（比如放到 D 盘），用参数启动：
        powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1 -DataDir "D:\云梦枢数据"

★ 它和安装版共用同一个数据目录：先装安装版、再解压这个包，两边看到的是同一份数据。
  但**不要同时开两个**（SQLite 同一时刻只允许一个写事务）。


需要自带什么
------------
只有一样：**你自己要用的那个大模型 API Key**（DeepSeek / 通义 / Kimi / Claude… 任意一家）。
不需要 Python、不需要 MySQL、不需要 Node —— 这个包里已经全带了。


常见问题
--------
· 提示"未知发布者"或 SmartScreen 拦截？
  程序没有代码签名（个人项目），点「更多信息 → 仍要运行」即可。

· 双击后窗口一闪就没了？
  说明启动失败。右键「启动云梦枢.cmd」→ 编辑，或者在这个目录里打开 PowerShell 执行
      powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1
  它会停在报错处，把红色文字发给我即可。

· 端口 8000 被占用？
  不用管，启动器会自动换一个空闲端口，并在窗口里打印实际地址。

· 浏览器没有自动打开？
  看窗口里打印的地址（形如 http://127.0.0.1:52341/console），手动粘到浏览器。

· 只出 Windows x64 版，macOS / Linux 未做。


想装成"像普通软件那样"
----------------------
去 Release 页下载安装包版本 `YunMengHub-Setup-x.y.z.exe`，
它会装上开始菜单图标、用独立窗口打开，卸载时保留你的数据。
