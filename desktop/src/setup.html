YUNMENG HUB · 交互式叙事引擎

云梦枢默认把数据存成本机的一个文件（SQLite）—— 不用安装 MySQL、 不用建库建号，装完就能用。角色卡、会话、消息都在里面， 向量记忆存在本地目录（也不用你管）。 这里填的配置会写进 应用数据目录（不在安装目录里），卸载重装不会丢。

如果你已经有 MySQL 8 并想用它，把下面的「存储方式」改成 MySQL 即可。

存储方式
MySQL 连接（选「本机文件」时不需要填）
安全密钥（可以留空）
高级选项（一般不用改）
默认（本机文件）不需要填任何东西：数据表由后端启动时自动创建， 密钥由后端首次运行时自动生成并保存在应用数据目录里。 「测试连接」会用真正的后端起一次服务并逐项检查数据库与向量库 —— 所以它通过就意味着"能用了"，而不是"格式看起来对"。 必填项没填时会当场告诉你，不会去起后端。
